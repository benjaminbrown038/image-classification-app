# image-classification-app


A lightweight Streamlit web application for real-time image classification
using a pretrained PyTorch ResNet-18 model.

## Features
- Upload `.jpg`, `.jpeg`, or `.png` images
- Real-time inference
- Displays top-5 ImageNet predictions with probabilities
- Modular architecture for easy model/dataset replacement

## Run Locally

```
pip install -r requirements.txt
streamlit run app.py
```
